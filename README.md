# **BioOne-Economic-Valuation**
* Type : Research Project
* Title : A study for the economic valuation of BioOne
* Periods : 2025.07.28. ~ 2025.11.18.

## **Research Purpose**
* Evaluation and analysis of the economic value of BioOne-related information services
* Estimate users’ willingness to pay (WTP) based on survey responses
* Identify differences in valuation patterns by user type and demographic characteristics
* Provide analytical evidence for service pricing and future platform utilization

## **My Analysis Contents**
* Conducted preprocessing and statistical analysis of survey response data
1. Structured survey data for single-bounded and double-bounded WTP estimation
2. Estimated WTP using logit models with bid-only and covariate-included specifications
3. Calculated WTP indicators including mean, median, truncated mean, standard error, and confidence intervals
4. Evaluated model performance using RMSE and checked model convergence issues
5. Visualized bid amount and maximum WTP distributions by user type and age group
6. Performed three-cluster segmentation based on utility-related variables
7. Prepared a numeric-coded dataset for SPSS-based ANOVA and post-hoc analysis
